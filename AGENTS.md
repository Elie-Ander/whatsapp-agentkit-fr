# AgentKit : instructions pour les assistants de code

Toutes les instructions de ce kit sont dans le fichier `CLAUDE.md`, à la racine du dépôt.
Lis-le EN ENTIER avant de faire quoi que ce soit, puis suis-le à la lettre.

Ce fichier a d'abord été écrit pour Claude Code, mais il s'applique à toi de la même façon :
partout où il dit « Claude Code », comprends « toi, l'assistant de code qui lit ce fichier ».

Quand l'utilisateur écrit « crée mon agent », `/creer-agent` ou une demande du même sens,
déroule les 5 phases de `CLAUDE.md` dans l'ordre, une question à la fois, en français.
